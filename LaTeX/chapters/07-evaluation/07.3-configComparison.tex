In diesem Kapitel werden die Einflüsse der verschiedenen variablen Parameter auf die Ergebnisse miteinander verglichen.
Dabei werden die einzelnen Parameter schrittweise betrachtet, um deren jeweilige Auswirkungen besser einordnen zu
können.
Zunächst wird der Einfluss des Delays untersucht, gefolgt von einer Analyse des Retry-Counts.
Anschließend werden die verschiedenen Strategien gegenüber gestellt und hinsichtlich ihrer Auswirkungen miteinander
verglichen.
Als Letztes wird Concurrency näher betrachtet, erst allgemein über alle Experimente hinweg, danach auf die
einzelnen Strategien bezogen.
